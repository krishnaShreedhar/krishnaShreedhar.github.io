On This Page

    Concept

    CUDA organizes parallel work in a three-level hierarchy:

    Grid
 └── Block (shares shared memory, can __syncthreads)
      └── Thread (one GPU lane, threadIdx / blockIdx)

    Global thread ID (1D): idx = blockIdx.x * blockDim.x + threadIdx.x

    Key APIs

    API Purpose
    <<<grid, block>>> Launch kernel with given grid/block dims
    blockIdx.x Block index within grid
    threadIdx.x Thread index within block
    blockDim.x Threads per block
    gridDim.x Blocks per grid

    Execution Flow

    flowchart TD A[Host: main] --> B[cudaMalloc / cudaMemcpy H2D] B --> C{Ablation loop over block_dims} C --> D[Compute grid_dim = ceil N / block_dim] D --> E[vector_add_kernel <<<grid_dim, block_dim>>>] E --> F[cudaEventRecord start/stop] F --> G[Compute mean time & bandwidth GB/s] G --> H{More block_dims?} H -- Yes --> C H -- No --> I[Correctness check vs CPU] I --> J[Log summary table] J --> K[cudaFree / exit]
